# Decisions log

One line of reasoning per decision. Code comments cite entries by number, for example `D-018`.
Numbers are never reused; entries that only concerned the development machine are not listed.

| # | Date | Decision | Reasoning |
|---|---|---|---|
| D-004 | 2026-09-20 | **Redis and Horizon run on the Linux host only.** Local cache, queue and session use the `database` drivers; `predis/predis` is installed so `redis` works in production without a PHP extension. | `laravel/horizon` needs `ext-pcntl` and `ext-posix`, which Windows lacks. Nothing in the domain code depends on the driver. |
| D-007 | 2026-09-20 | **No Tailwind.** Removed from the scaffold together with `@tailwindcss/vite`. | The design system is the two ported stylesheets, `tokens.css` and `components.css`; Lato and IBM Plex Mono load from Google Fonts. |
| D-009 | 2026-09-20 | **Tests run against a real MySQL database (`rimify_test`)**, never SQLite in memory. | The engine's SQL uses window functions, `SIGNAL` triggers, CHECK constraints and FULLTEXT; SQLite would silently pass code that fails on MySQL — exactly the "reads correct and is wrong" class of defect. |
| D-010 | 2026-09-20 | **Strict mode is asserted at boot** in `AppServiceProvider` on every MySQL connection, throwing if a required `sql_mode` flag is absent. | A missing flag would let R-03 fail open. |
| D-011 | 2026-09-20 | **`ONLY_FULL_GROUP_BY` is kept** in the connection's `modes`. | It is the MySQL 8.4 default and it catches an aggregate query silently returning arbitrary rows. |
| D-012 | 2026-09-20 | **Inertia v3** (`inertia-laravel` 3.3, `@inertiajs/vue3` 3.7). | It is what Composer resolves against Laravel 13, and server and client adapters must share a major version. |
| D-013 | 2026-09-20 | **Migrations are grouped by bounded context** in `database/migrations/{fitment,commerce,vehicle_import,integration}`, registered with `loadMigrationsFrom()`; ordering stays global by filename. | One context can be migrated and tested alone (`RIMIFY_MIGRATION_SLICE`), and 40+ migrations stay navigable. |
| D-014 | 2026-09-20 | **Edge case E3 ships as the literal Figma rule** — a stored vehicle that has never entered the booking process shows a plain header — behind one constructor flag on `HeaderModeResolver`. | Implement what was drawn; keep the more useful variant one line of configuration away for design review. |
| D-015 | 2026-09-20 | **Tablets receive the desktop layout.** `Sec-CH-UA-Mobile` outranks the User-Agent; `?view=desktop\|mobile` pins a layout in a 7-day cookie and `?view=auto` releases it. | The mobile documents are designed for 390px with a thumb-reach bottom nav; a 768px+ viewport is served better by the desktop document. |
| D-016 | 2026-09-20 | **The audit trail is `spatie/laravel-activitylog` with its table renamed `audit_logs`**, extended with `ip_address`, `correlation_id` and `actor_email`, and made append-only by triggers. | One table instead of two competing logs. |
| D-017 | 2026-09-20 | **`App\Domain\Fitment\Derivation\ReferenceTables` is the single source** for the load-index and speed-symbol figures; the database tables are seeded from it and a test asserts they are equal. | The compliance owner can inspect real tables, and the seed and the test oracle cannot drift apart. |
| D-018 | 2026-09-21 | **The speed-symbol derivation follows the stated rule. `P` is correct for 148 km/h.** | The spec's worked example printed `T` because its table omitted N, P, Q, R, S and U, so `T` was the first symbol still present — a defect in the example, not the rule. The complete scale (`L M N P Q R S T U H V W Y (Y)`) is seeded, `SpeedSymbolDeriver` is asserted at every boundary, and a test proves every symbol is reachable, so a truncated table can never pass unnoticed. |
| D-019 | 2026-09-21 | **A safety margin above the derived legal minimum is configuration, not data:** `config/rimify.php` → `speed_symbol_margin_steps` and `load_index_margin_steps`, both `0` by default. | Hard-coding a margin would make a commercial choice indistinguishable from the legal figure. A margin may only raise the requirement — a negative value throws. |
| D-020 | 2026-09-21 | **The supersession chain is guarded in three layers:** the model, a `BEFORE UPDATE` trigger raising `SQLSTATE 45000`, and `SupersedeChain` for cycles. | MySQL refuses a CHECK on an `AUTO_INCREMENT` column and `BEFORE INSERT` cannot see `NEW.id`, so no single layer covers every path. A chain too deep to verify is refused rather than followed. |
| D-021 | 2026-09-21 | **The four `RIMIFY-GARANTIE` basket rows are** `Garantierte Passgenauigkeit` · `Gutachten zu jeder Felge` · `Montiert und gewuchtet` · `Express-Versand aus Deutschland`. **Client confirmation pending.** | They mirror the hero trust strip, so the promise made above the fold is repeated at the basket. |
| D-022 | 2026-09-21 | **Where the FAQ sources differ, the Copy Pack wins** (Q2, Q3, Q6, Q7, Q8). | The design specification is the earlier draft. Q1, Q4 and Q5 are identical in both. |
| D-023 | 2026-09-21 | **Contact details live once, in `config/rimify.php`**, and every appearance renders from there. **Client confirmation pending.** | The homepage and the Kontakt page carried different numbers. Tests police the canonical values and forbid a hard-coded phone or e-mail in any renderable file. |
| D-024 | 2026-09-21 | **Legal pages ship with real section headings and a visibly marked placeholder body** — `[Rechtstext folgt von der Kanzlei — Abschnitt: <heading>]`. | German legal text is drafted by the client's Kanzlei, not by developers. The page is honest about what is missing. |
| D-026 | 2026-09-21 | **R-03 outranks R-06.** A vehicle whose axle loads or top speed could not be parsed yields `UNKNOWN` even when the Gutachten states its own minimum. | A document minimum says what the *wheel* requires, not what the *car* can carry. | D-027 | 2026-09-21 | **An unrecognised speed symbol printed by a document is ignored, not trusted.** The derivation governs alone. | A symbol absent from `speed_symbol_table` has no rank; treating it as a minimum would compare as "no requirement" and relax the answer in the permissive direction. |
