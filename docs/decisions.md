# Decisions log

One line of reasoning per decision. Code comments cite entries by number, for example `D-018`.
Numbers are never reused; entries that only concerned the development machine are not listed.

**The standing rule (2026-09-29, CLAUDE.md §9):** anything reversible in under an hour is decided, built and
recorded here — the date, the choice, the reason, the commit — without asking first. Between two behaviours
that already disagree, the one used elsewhere in the product wins. Asked first are only: the irreversible (data
loss, money moving, a production deploy), what needs the operator's credential, file or purchase, what
contradicts CLAUDE.md, and what changes what a customer is told about the legality of a wheel on their car.
